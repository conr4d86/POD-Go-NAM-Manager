# 0.8.0 — Interfaz y escalado / Interface and scaling

## Español

- Diseño unificado: pasos circulares, botones redondeados, estados visibles y selector Español / English.
- Escalado proporcional desde las medidas originales; maximización disponible y desplazamiento en ventanas muy pequeñas.
- Biblioteca más limpia: confirmación al sustituir un NAM, con copia previa e IR protegidos.
- Nivel de entrada manual. Automático conserva 0 dB de entrada, sin analizar audio; salida a −5 dB.
- CF v8 y motor incluidos, sin firmware oficial. Quienes ya usan v8 no necesitan reinstalarlo.

## English

- Unified design: circular steps, rounded actions, visible states and Español / English switch.
- Proportional scaling from original metrics, maximizing and scrolling in very small windows.
- Cleaner library: confirmation and backup when replacing NAMs; cabinet IRs stay protected.
- Manual input trim. Automatic preserves 0 dB input without analyzing audio; output stays at −5 dB.
- v8 CF and installation engine included; official firmware excluded. Existing v8 users do not need to reflash.

Offline checks and native screenshots cover both languages and window sizes.
This release does not add a new hardware validation claim; see VALIDATION.md.
