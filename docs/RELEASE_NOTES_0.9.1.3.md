# POD Go NAM Manager 0.9.1.3 · CF v9

## Español

Un ejecutable para Windows reúne Biblioteca NAM, TONE3000, Custom Editor y Firmware / Restaurar. Incluye CF NAM Conr4d v9 para la POD Go estándar con base 2.50. Si ya tienes CF v9 compatible, abre el nuevo ejecutable.

- **Catálogo TONE3000.** Busca tonos o creadores, filtra por pestañas de equipo y ordena los resultados. La lista carga hasta 200 resultados inicialmente y añade más al desplazarte. Al pulsar el nombre del creador en la ficha, se abre el buscador con su filtro activo. La × quita ese filtro.
- **Reproducción.** Usa Play y Pausa desde los resultados, las variantes de la ficha y los NAM descargados con un paquete público asociado. La reproducción de un paquete avanza por sus variantes en orden alfabético. Las muestras usan Hotrod - Guitar y Mesa 412 OS cuando el reproductor ofrece ese ajuste. La ficha también incluye el reproductor completo con «Sample» y «Plug in and play».
- **Descargas.** Abre un paquete con doble clic o con «Abrir selección». La lista de variantes está ordenada por nombre. Descarga una o varias a la carpeta `TONE3000`, junto al ejecutable. Las tarjetas de «NAM Descargados» tienen portadas cuadradas y la misma altura. La × roja pide confirmación antes de enviar el paquete a la Papelera.
- **Biblioteca NAM.** Se conecta al entrar cuando la POD Go está disponible. Puedes preparar varios NAM descargados y revisar las posiciones libres propuestas. También puedes extraer una captura de un ZIP local y ajustar su nombre corto, volumen y destino. Se corrigió el aviso que podía aparecer al volver desde TONE3000.
- **Custom Editor.** Selecciona presets y snapshots, arrastra bloques, edita parámetros y asignaciones, y guarda el preset activo por USB. Incluye el cambio de un ampli de fábrica a NAM A2 Lite, la lectura de confirmación de Global EQ, avisos de guardado, Deshacer/Rehacer y valores visibles durante el arrastre de asignaciones.
- **Interfaz.** La cabecera usa el logo de TONE3000 y los títulos de columna están en negrita. Las listas muestran «Cargando…» durante las consultas. Las pestañas de equipo incluyen «Pantallas IR».

Para una primera instalación, crea un backup `.pgb` con POD Go Edit y cierra esa aplicación antes de conectar el Manager. Para importar un preset individual `.pgp`, restaurar un banco completo o reorganizar los presets User, usa POD Go Edit.

## English

A single Windows executable includes NAM Library, TONE3000, Custom Editor and Firmware / Restore. It bundles CF NAM Conr4d v9 for the standard POD Go on firmware 2.50. If you already have compatible CF v9, open the new executable.

- **TONE3000 catalog.** Search tones or creators, filter by gear tabs and sort results. The list loads up to 200 results initially and adds more as you scroll. Clicking the creator name in a pack opens Search with the creator filter applied. Use × to clear it.
- **Playback.** Play and pause from search results, pack variants, and downloaded NAM lists linked to a public pack. Pack playback advances through its variants alphabetically. Samples use Hotrod - Guitar and Mesa 412 OS where the player offers that cabinet option. Pack details also include the full player with “Sample” and “Plug in and play.”
- **Downloads.** Open a pack by double-clicking or choosing “Open selection.” Variants are sorted by name. Download one or more to the `TONE3000` folder next to the executable. Download cards have square artwork and a consistent height. The red × asks for confirmation before moving a pack to the Recycle Bin.
- **NAM Library.** Connects when opened if the POD Go is available. Prepare multiple downloaded NAMs and review the suggested free slots. You can also extract a capture from a local ZIP and set its short name, level and destination. This release fixes an error that could appear when returning from TONE3000.
- **Custom Editor.** Select presets and snapshots, drag blocks, edit parameters and assignments, and save the active preset over USB. Includes factory amp to NAM A2 Lite switching, Global EQ readback, save feedback, Undo/Redo and values shown while dragging assignment handles.
- **Interface.** The header uses the TONE3000 logo and column headings are bold. Lists show “Loading…” during requests. Gear tabs include Cabinet IRs.

For a first installation, make a `.pgb` backup in POD Go Edit and close it before connecting the Manager. Use POD Go Edit for individual `.pgp` imports, full backup restores and reorganizing User presets.
